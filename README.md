# Trabajo Práctico Integrador - Gestión de Datos de Países

## Descripción

Este proyecto consiste en una aplicación desarrollada en Python la cual permite gestionar datos de paises utilizando estructuras como listas y diccionarios, almacenadas en un archivo csv

El sistema permite:

* Alta de países.
* Actualizar tanto población como superficie.
* Buscar países por nombre.
* Filtrar países por continente.
* Filtrar por rango de población.
* Filtrar por rango de superficie.
* Ordenamiento por nombre, población y superficie.
* Generar estadísticas generales.

## Tecnologías utilizadas

* CSV
* Listas
* Diccionarios
